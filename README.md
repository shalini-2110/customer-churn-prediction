# Customer Churn Prediction — Data Science Internship Project

## Overview
This repository contains the work for a data science internship project focused on predicting
customer churn in the telecommunications industry using Python-based machine learning techniques.

## Project Structure
```
├── docs/            # Research proposal and written reports
├── notebooks/       # Jupyter notebooks (EDA, modeling, evaluation)
├── data/            # Raw and processed datasets (or links to them)
├── src/             # Reusable Python scripts (preprocessing, training, evaluation)
└── README.md
```

## Week 1 — Research Proposal
See `docs/Research_Proposal_Customer_Churn.docx` for the full research proposal, including:
- Problem statement and significance
- Research objectives and scope
- Proposed methodology (data collection, preprocessing, modeling, evaluation)
- Timeline and resource allocation
- Risk assessment and mitigation strategies

Python, Pandas, NumPy, Scikit-learn, XGBoost, SHAP, Matplotlib/Seaborn
